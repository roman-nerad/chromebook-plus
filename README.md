# Chromebook Plus pro učitele

Jednoduchá webová stránka vytvořená jako opakování z předchozích ročníků.

## Co projekt obsahuje

- `index.html` – základní HTML struktura, nadpisy h1, h2, h3 a SEO informace
- `style.css` – externí CSS, layout pomocí gridu, relativní jednotky (rem, em, %, fr, vh) a efekt při najetí myší (hover)

## Jak stránku zobrazit

Stačí otevřít soubor `index.html` v internetovém prohlížeči.
